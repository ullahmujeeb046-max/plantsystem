# Suggested live demonstration

Start the program:

```bash
python3 main.py
```

Try these sample inputs one at a time:

1. `The lower leaves have dark brown spots with concentric rings and yellowing.`
2. `There is a white powdery coating on the leaves and the leaves are curling.`
3. `The plant suddenly wilts although the soil is moist and the roots have galls.`
4. `The bottom of the tomato fruit has a dark sunken patch and soil moisture is irregular.`

Then type `help` to see examples, or `quit` to exit.

To run the automated tests:

```bash
python3 -m unittest discover -s tests -v
```
